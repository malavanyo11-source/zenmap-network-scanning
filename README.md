# zenmap-network-scanning
🛠️ Zenmap Network Scanning Project
📌 Introduction
This repository documents 
**Week 2 | Project Module 5: Network Scanning with Zenmap**.  
Zenmap is the official GUI version of Nmap, a free and open‑source security scanner used by cybersecurity professionals and ethical hackers.  
This project demonstrates how to use Zenmap to discover live hosts, IP addresses, MAC addresses, and visualize network topology.

🎯 Tasks
1. Download & install Zenmap on Windows PC  
2. Find local IP address & LAN subnet  
3. Discover live hosts in subnet  
4. Count number of live hosts  
5. Identify IP addresses of live hosts  
6. Identify MAC addresses of live hosts  
7. Save output topology in PDF format
